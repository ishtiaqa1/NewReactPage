# Ishtiaq Akanda — Portfolio Website

## Project Introduction

**What is this project?**
A personal portfolio website showcasing my projects, skills, and background as a developer. It features a home page, an about section with a full tech stack breakdown, a projects gallery, and a contact page.

**Why was it built?**
Built to give a central place to showcase my work and tell my story as a first-generation Bengali-American from the Bronx who found his way into software engineering through hands-on learning at Marcy Lab School.

**Who is it for?**
Recruiters, hiring managers, fellow developers, and anyone curious about my work and background.
